## About Me

Hi, I'm harbs20. I build AI tools, Minecraft projects, web apps, and Arduino projects.

Right now I am focused on `revy`, a local-first personal AI sidekick with memory, provider routing, a CLI, and a local daemon.

I am also a Minecraft speedrunner, so a lot of my projects start from tools I actually want to use.

## Currently

- Building: `revy`, a Node-powered AI assistant core for memory, artifacts, providers, and local workflows.
- Shipping: Minecraft tooling like `TradingMod` and speedrun-focused utilities.
- Learning: Java, Node.js, React, local-first AI systems, and cleaner project architecture.
